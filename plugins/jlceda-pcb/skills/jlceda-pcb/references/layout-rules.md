# 摆件与布线规则（与工具无关，实际做板踩过）

## 摆件
- **先按信号流排件，再布线**。乱摆交给自动布线，结果是电源走底层把地切碎、信号到处绕。
- 先定大件：模组（天线贴板边）、连接器（开口朝板边，可略伸出板边 0.3~0.5mm）。
- 电源主干一条路：输入 → 保险丝 → 主干 → LDO / 大电流开关 → 输出口；大电流件靠近各自的连接器。
- 小件挨着它服务的引脚，**引脚朝向对着去向**（如 LED 阳极朝限流电阻），否则自己的另一个焊盘挡路。
- 模组底边一排 0.8mm 间距引脚，往外逃逸要通道：模组与下方元件之间留 ≥1.5mm；排针横放在模组下方时留 ≥2.5mm。
- ESP32-C3-MINI-1：USB D+/D-、UART 在右侧，3V3/EN 在左侧 → Type-C 放右侧，LDO/EN 阻容放左侧。
- 全部元件放顶层（单面贴片省钱）；排针定义、板名可放背面丝印。
- 缩小尺寸先算面积账（连接器纵深、模组、排针长度）。两个口正反面叠放会让两根线同时插时打架、Type-C 外壳脚还是通孔，一般不可行；长条形“两端各一个口、天线朝长边”是常见解。

## 天线与禁布
- 天线带两层都禁铜/走线/过孔，**比模组宽度两侧各多 ~3mm**（模组封装自带禁布区只覆盖模组宽度）。带两侧空位可放无铜 NPTH 安装孔（建议尼龙螺丝）。
- 模组本体下方：顶层禁走线/过孔（底部是大片接地焊盘）；底层可走线。
- Type-C 外壳接 SHIELD（1M//4.7nF 到地）时，外壳下方禁打 GND 过孔。
- 使用时天线那一侧不要贴金属（铁壳、金属墙、灯条铝槽），外壳用塑料。

## 布线
- USB-C 的 D+/D- 焊盘交错（B7 D-、A6 D+、A7 D-、B6 D+），自动布线常连不全：先手动/脚本预布，D+ 在焊盘一侧连 U 形、D- 在另一侧连 U 形。连接器旋转后方向要跟着换算。
- 去耦电容的地先就近连到芯片 GND 脚再自动布线，否则常被信号线围成孤岛；但别给 SOT-23 LDO 中间的 GND 脚预布（会把两侧 IN/EN 围死）。
- 宽线进不了细间距焊盘：0.8mm 电源线接不进 0.5mm 间距的 SOT-666 → 换 SOT-23-6 封装或局部窄线。
- 大电流（2A）路径：主干 1.2mm 以上、两层都可走；通孔连接器的 GND 焊盘与铺铜全连接，不用花焊盘。
- GND 用两面铺铜 + 每个贴片 GND 焊盘就近打孔 + 网格缝合过孔；贴片焊盘全连接，手焊通孔用花焊盘。
- 铺完检查孤岛：没有过孔连到主地的铜皮要补孔或删除。

## 电路常见坑
- LED 符号 1=K、2=A，串联时注意方向。
- 复位后带内部上拉的 GPIO 不能直接驱动 MOS 栅极（上电瞬间误导通）。
- 输出口外壳可能接地（USB-A 等）→ 用高边开关。
- 感性负载（电机）加续流二极管；USB 5V 总电流上限 3A，保险丝按负载选。
