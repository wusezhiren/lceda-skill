# 电路设计检查清单

画原理图前、选料后各过一遍。每条都附原因，便于向用户解释取舍。

## 供电

- **USB-C 只当 5V 输入时，CC1/CC2 各 5.1kΩ 下拉**。没有它，C-to-C 充电头不会输出 5V。
- **USB 5V 的上限是 3A**（默认 Type-C 电流）。负载总电流 + MCU 峰值（ESP32 WiFi 约 0.35A）要在这以内；超过就要外接电源或 PD 诱骗。
- **只用 USB 供电时，LDO 通常比 DC-DC 合适**：待机功耗被充电头空载损耗淹没，LDO 便宜、小、无电感、不干扰 WiFi。LDO 发热 = (Vin−Vout)×I，与型号无关；选低 Iq、≥500mA（ESP32 峰值）。
  - 推荐 RT9080-33（2µA，600mA，SOT-23-5）；更便宜可换 ME6211C33（引脚兼容）。别用 AMS1117（Iq 5mA、压差 1.1V）。
- 自恢复保险丝：保持电流 ≥ 最大负载；看内阻——它在大电流路径上会成为最热的元件、还会压降。2A 负载用 1206 3A（内阻 10~50mΩ）。
- 储能电容放在负载附近，防止电机启动/灯条 PWM 拉低 5V 导致 MCU 复位。

## ESP32 系列（以 C3 为例）

- **原生 USB（GPIO18/19）可直接烧录和打日志**，不需要 USB 转串口芯片；但固件进深睡或改了这两个脚后 USB 会消失，所以**必须保留 BOOT(GPIO9) + RST(EN) 按键**救砖。
- EN：10k 上拉 + 1µF 到地（上电延时）。
- **Strapping 脚**：GPIO2、GPIO8 上拉为高；GPIO9 是 BOOT。下载模式要求 GPIO8 为高。
- **复位后默认带内部上拉的脚不要直接驱动 MOS 栅极**：C3 的 GPIO6（MTCK）复位后 WPU（约 45k），与 100k 下拉分压约 2.3V，会让 MOS 开机误导通。看数据手册 Pin Overview 表 “After Reset” 列；C3 上 GPIO7、GPIO10 复位后只开输入、无上拉，适合做开关输出。
- 深睡唤醒只能用 RTC GPIO（C3 是 GPIO0~5），按键/传感器放这些脚。
- 状态灯接成“GPIO 拉低点亮”，平时不耗电。

## MOS 开关

- **低边 N-MOS（AO3400A）**：3.3V 栅极可直接驱动（2.5V 下约 30~50mΩ）。栅极串 100Ω、**下拉 100k**（上电/复位/深睡时保持关断）。
- **感性负载（电机、继电器、电磁阀）必加续流二极管**（肖特基，跨接在负载两端）；电机两端再并 100nF 吸收火花。接 LED 可不贴。
- **输出口是 USB-A（或任何外壳可能接地的连接器）时用高边开关**：P-MOS（AO3401A）切 +5V，GND 始终接地；栅极上拉到 5V，再用一颗 N-MOS 做电平转换（GPIO 高 = 开）。低边切 GND 的话，USB 插头外壳一碰地就把开关旁路了。
  - 栅极上拉 4.7k、Ciss 约 650pF → 关断时间常数约 3µs，PWM 建议 ≤1kHz。
- 发热估算 P = I²·Rds(on)：AO3400A 2A 约 0.15W，AO3401A 2A 约 0.24W（SOT-23 需大面积铺铜）。
- 三极管（S8050 等）只适合 <100mA 的 LED；电机/灯条用 MOS。
- 带遥控/控制芯片的 USB 灯条只能开关，不能 PWM（会把它的控制芯片供电切乱）。

## 保护与 EMC

- USB 数据线 ESD：USBLC6-2SC6（SOT-23-6，VBUS 脚同时给 VBUS 钳位，可省一颗 TVS）。
- USB 外壳：1MΩ // 4.7nF 接 GND（泄放静电，不形成地环路）。
- 只控制 5V 低压负载；**明确告诉用户不要接 220V**（需要继电器 + 隔离方案）。

## 选料原则（嘉立创 SMT）

- 优先平台当前有库存、可采购并支持目标贴装工艺的器件；先查料号、库存、封装及贴装状态，再定型画图。有库符号不等于可采购，缺货料先查有货替代，替代须复核引脚和电气规格。BOM 记录查询日期，导出前复核可得性。
- 有货替代的价格以同采购量、币种、税费口径和报价日期比较，目标价差 ±5%，通常不超过 ±10%；计入扩展料费用及整板成本。超过 +10% 先找其他替代，确需采用则列明价格和理由请用户确认。降价超过 10% 时复核规格及采购条件，不因更便宜直接排除；无可靠报价则标记待核价。
- 优先基础库（无换料费）；每多一种扩展料加一次换料费。
- 在用户“尽量小”的要求下仍要留余量：大电流件（MOS、保险丝、连接器）不要为了小而选不够的封装；手焊/插拔的连接器用可靠型号。
- 连接器额定电流要 ≥ 负载：1.25mm 端子约 1A、PH2.0 约 2A、XH2.54 约 3A；焊线焊盘用 0.5mm²/AWG20 线可过 2A+。
- 每个选择写进 BOM 备注（为什么、能否替换），用户会问。
