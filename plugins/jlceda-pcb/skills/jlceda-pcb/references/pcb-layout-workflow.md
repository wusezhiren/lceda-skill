# PCB 布局流程（脚本化摆件，按焊盘坐标迭代）

对象级 API 摆件时看不到画面，最常见的失败是：只按器件中心/外形框摆、互相压焊盘、板子面积不够才发现、丝印全叠在一起。按下面顺序做，每一步都有可量化的检查。

## 0. 选型先于布局

- 阻容优先 0201，其次 0402；IC/MOS 优先 SOT-523/SOT-353/SOT-666/DFN；晶振 2016；保险丝 0603。只有载流、散热、射频电感电流、焊线等硬约束才放大，并写明理由。
- 换小封装后**原理图符号引脚间距常变**（如 USBLC6 SOT-666 符号脚距 10，SOT-23-6 版是 30；2N7002T 的 S/D 位置与 2N7002 不同），原连线会 `create failed!`。换料后先用 `place()` 读一遍新符号引脚再改连线。

## 1. 面积账（摆件前）

列出所有器件的焊盘包络面积（导入 PCB 后 `pcb_dump.js` 里 pads 外接框即可）+ 间距系数：

| 类别 | 系数 |
|---|---|
| 0201/0402 阻容 | 包络面积 × 3 |
| SOT/QFN/IC | × 1.8 |
| 连接器、按键、LED、大焊盘 | × 1.3 |

再扣掉天线禁布区（板载 PCB 天线约 15×5mm + 两侧净空）、板边 0.3mm、输出焊盘区。合计 > 可用面积的 70% 时，先换小封装/改板框/挪件到背面，并告诉用户，别硬摆。

## 1.5 模块化布局（默认做法）

**先拆模块、按官方参考设计排好每个模块，再把模块整体集中摆到板上**，不要把全部器件一次性平铺调坐标。

1. **拆模块**：与原理图分区一致，例如 MCU 核心（芯片 + 去耦 + 晶振）、射频匹配 + 天线、USB-C 输入 + ESD + CC、保险丝/储能、LDO、负载开关（P-MOS + 驱动）、RGB（电平转换 + 灯珠）、按键、测试点。每个模块写明“入口/出口”网络和朝向（如 RF 出口朝天线、VBUS 出口朝保险丝）。
2. **找参考布局**（官网优先，记录出处）：
   - 主控/射频：厂商硬件设计指南的 PCB 布局章节 + 官方开发板/参考设计的 Gerber/PCB（如乐鑫《ESP32-C3 硬件设计指南》“PCB 版图设计”、ESP32-C3 参考设计/DevKit 资料：去耦电容逐脚贴近、匹配电路紧贴 LNA_IN、晶振远离射频与板边、EPAD 地孔阵列、天线净空）。
   - 电源 IC/LDO/DC-DC：数据手册 “Layout Guidelines / PCB Layout Example”（输入输出电容贴脚、地回路最短、散热铜皮）。
   - ESD/USB：ESD 器件数据手册推荐布局（ESD 紧靠连接器、信号先经 ESD 再到芯片、差分对等长走直）。
   - MOS/大电流：数据手册焊盘与散热铜皮建议、电流路径最短不绕。
   - LED/电平转换、晶振：数据手册的去耦、走线长度与负载电容位置要求。
   找不到官方布局时按数据手册文字要求排，并在交付说明里标注“无官方参考布局”。
3. **模块内排布**：用局部坐标（锚点通常取模块主器件中心或入口焊盘）写成 `{位号:[dx,dy,rot]}`，先单独 `pcbPlace` 到空白处，`pcb_dump.js` + `pcb_check.py` + `pcb_render.py` 查一遍，模块内部达到参考布局要求（关键距离逐条核对，例如去耦电容到电源脚 ≤1mm、晶振串联电感/负载电容贴 XTAL 脚）后冻结。
4. **集中布局**：按信号流把模块作为整体放到板上（`pcbPlaceModules({MCU:{at,rot,parts}, …})`，见 `lib.js`），只调模块锚点和旋转；模块之间留布线通道，跨模块网络（电源主干、USB、控制线）走向顺畅、不穿越射频与晶振区。必要时再微调模块内少数器件，但不打乱已核对的参考布局关系。
5. 交付说明列出各模块参考的官方资料（文档名/章节），以及与参考布局不一致之处和原因。

## 2. 分区与锚点

1. 固定机械件：板框、连接器（开口朝板边，外壳前沿伸出 ≤0.5mm，看 `bb` 而不是器件中心）、天线（板边）、焊线焊盘、按键（可触达的边）。
2. 主芯片定方向：**按引脚功能决定旋转**，让 RF 脚朝天线馈点、USB 脚朝连接器、晶振脚有空位。旋转语义实测：`rotation` 逆时针为正，`rot=90` 时 (u,v)→(−v,u)，`rot=270` 时 (u,v)→(v,−u)；两脚阻容 `rot=0` 时 1 脚在 −x，`rot=90` 时 1 脚在 −y。
3. 读芯片真实焊盘坐标（`pcb_dump.js`），外围件**相对引脚坐标**摆：去耦电容电源脚对芯片对应脚、地脚朝外打孔；射频链按信号顺序紧排；晶振 + 负载电容 + 串联电感贴近 XTAL 脚。

## 3. 摆 → 查 → 看，循环

```bash
python3 scripts/lceda.py run place.js --timeout 200          # 自己的摆件表：{位号:[x,y,rot,'TOP'|'BOTTOM']}，用 lib.js 的 pcbPlace()
python3 scripts/lceda.py run scripts/pcb_dump.js --timeout 200 > dump.json
python3 scripts/pcb_check.py dump.json --gap 0.15             # 焊盘间距、近板边、器件互压
python3 scripts/pcb_render.py dump.json r.png all             # 目视
```

- `pcb_check.py` 报 0 项再往下走；0.1~0.15mm 的异网络间距板厂能做，但留给布线的通道就没了，核心区留 ≥0.2mm。
- 单个坐标改动优先用摆件表覆盖，别手改多处脚本；每轮都重新 dump，不凭记忆算坐标。
- `getPrimitivesBBox` 的外形框含丝印，比焊盘大很多，只用于粗看；判断互压用焊盘包络。

## 4. 固定几何（布线前）

在本地脚本里一次性生成并检查后再下发：射频线（50Ω 线宽按层叠算）、匹配件地孔、EPAD 地孔阵列、大电流铜皮（Fill）与换层过孔阵列、PCB 专用焊盘（焊线孔、测试点）、每个地焊盘就近地孔（候选位置逐一查与异网络焊盘/铜皮/测试点的间距）。

- 过孔穿所有层：放地孔时要避开**任何层**上的异网络铜皮（例如背面 +5V 铜皮），否则就是短路。
- 板载 PCB 天线：`lib_Footprint.updateDocumentSource` / `openInEditor` 在 4.1.93 调用即抛异常（原样回写也一样），做不了自定义封装时直接在 PCB 上用 Fill 画天线铜皮；天线铜皮归馈点网络，短路臂归 GND，交界处会剩 1 条 Fill↔Fill 间距报错，交付时作为“设计内网络短接”单独说明。天线区用 `pcb_PrimitiveRegion`（MULTI，NO_POURS + NO_INNER_ELECTRICAL_LAYERS）禁铜。
- 原理图里的短接标识（`createShortCircuitFlag`）会把两个网络整体合并（导入后两边焊盘全变成 GND），不能当 net-tie 用。

## 5. 布线（默认 Freerouting）

```bash
python3 scripts/freeroute.py --out work/fr --passes 20      # 默认剔除 GND（靠铺铜+地孔）
```

- 射频线、功率铜皮、地孔、天线等先画好，作为固定图元进入 DSN；预布线在途经的焊盘中心断开。GND 用 `-inc` 忽略（保留网络），规则区缺失时自动注入 keepout。
- 内置 `autoRouting()` 在 50 件 4 层小板上同步调用 10 分钟超时、结束后走线被回滚；`startAutoRouting()` 作业 9 分钟 16%。只用于个别网络补线。
- 布完：重建铺铜 → `drcSummary()`；未布通先看是不是摆件把通道堵死，而不是一味加轮数。

## 6. 丝印

```bash
python3 scripts/lceda.py run scripts/pcb_silk.js --args '{"size":0.6}' --timeout 200
python3 scripts/lceda.py run scripts/pcb_dump.js > dump.json && python3 scripts/pcb_check.py dump.json --silk
```

位号统一字高（0201 板 0.5~0.6mm、线宽 0.1mm）、居中、不旋转；脚本按器件四周 8 个方位逐圈找空位，放不下的隐藏并列出（交付时说明靠装配图定位）。功能标注（OUT+/OUT−、测试点名、板名版本）用 `pcb_PrimitiveString` 单独放，放好后再跑一次 `pcb_silk.js` 前先把这些位置作为障碍考虑（必要时手动微调）。

## 7. 验收

铺铜重建 → 立创 DRC（分类报告：连通/间距/短路/板边/丝印）→ 渲染图 + 3D 目视 → 网表与原理图节点集合一致。不以“函数返回 true”“布通率”代替验收。
