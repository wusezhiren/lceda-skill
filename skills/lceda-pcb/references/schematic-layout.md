# 原理图模块化排版

## 绘制顺序

1. 根据电路功能建立模块清单和位号归属，例如电源输入与保护、3.3V 稳压、主控最小系统、射频与天线、按键、MOS 驱动与输出、RGB LED。按复杂度合并或拆分，不照搬固定模块数量。
2. 先把全部已选元器件放入原理图临时区域，核对型号、数量、符号引脚及位号，再开始正式排版。不要一边随意加器件一边铺满默认页面。
3. 根据实际符号边界估算每个模块的宽高，包含引脚出线、位号、型号、网络标签、模块标题、说明文字及连线通道。不能以 PCB 封装面积推算原理图面积，也不能只按器件数量平均分区。
4. 默认从 A4 页面开始，先安排模块内部的相对位置，在 A4 可用范围内估算模块框并排版。按信号流及电源流排列模块，预留模块间距、页边距和标题栏；可先给模块边界预留约 20%～30% 调整空间，最终以实际文字和连线边界为准。无需在开始前确定最终页面大小。
5. 绘制过程中实际空间不足时，再增加原理图图页或调整为更大的标准图纸；标准图纸不适合时使用编辑器支持的自定义尺寸。不要为了挤进 A4 而缩小到文字难以阅读或压缩必要的连线通道。需要调整页面时，通过当前版本官方 API 核对设置方法并实际修改页面，不把缩放视图当作修改页面大小；调整后重新核对图框和标题栏。
6. 按模块摆放器件，绘制红色分区线（推荐版式）或红色外框，每个模块放清晰标题，例如“主控 / ESP32-C3”“电源 / 5V → 3.3V”“按键 / BOOT、RESET”“驱动 / 高端 MOS 2A”“LED / RGB”。标题和关键说明须可读，避免与器件或连线重叠。
7. 框线使用非电气矩形或折线图元，并设置为红色；不要用带网络的电气导线画装饰框，以免引入错误连接。框线不穿过器件、引脚、网络名或其他文字，红框和标题在导出预览中也要可见。
8. 最后连接模块内电路和跨模块信号。同一模块内部优先用实际导线连接，明确呈现电流路径与控制关系，不把每个器件引脚都接短线标签来代替局部电路。跨模块及公共电源可使用同名网络标签，名称保持一致；确需在模块内用标签时避免让读者反复找同名网络。关键电压、输出极性、额定电流、默认开关状态和调试预留在对应模块说明。
9. 模块内部按实际运行原理摆放，通常从左到右呈现输入、保护或滤波、处理或驱动、输出，电源在上、接地在下。例如稳压模块按“5V 输入 → 输入保护/滤波 → 稳压芯片 → 输出滤波 → 3.3V 输出”组织，旁路电容画成对应电源节点对地支路，不画成串联器件；电阻、电感仅在电路实际需要时加入，不为符合示意顺序虚构电路。驱动模块按“GPIO → 驱动管 → 功率 MOS → 负载接口”，RGB 模块按“数据输入 → 电平转换 → 串联电阻 → DIN”排列。允许局部移动、旋转器件和重接受影响导线以提升原理可读性，保留其余图元与模块。

## 推荐版式：分区式 EVB 原理图（默认采用）

参照成熟开发板原理图（版本页 + 框图页 + 功能页，每页 2×2 分区）提炼，`scripts/sch_style.js` 已实现，画图脚本拼在它后面运行：
`python3 scripts/lceda.py run scripts/sch_style.js my_page.js`。

- **页面骨架**（A4，坐标 10mil，图纸 1170×825，Y 向上）：左侧 x≈20~145 为接口栏，x=150 一条粗红竖线；电路区 x=650 竖线、y=420 横线分成 2×2，分隔线红色细线（`frame()`）。右下角标题栏保留区约 x≥455 且 y≤215，右下分区只用 y≥220，左下分区可延伸到底部（x<445）。
- **接口栏**：顶部写 `P页码 页名` 和 2~3 行本页摘要；下面“跨页接口”逐行列出跨页信号：红色页码 `[3]` + 网络端口符号 + 带网络名短线（`PORT()`）。只在 PCB 落地的对象（测试焊盘、输出焊盘、天线）在接口栏写明“PCB 放置”。
- **模块标题**：每个分区左上角一行蓝色粗体、带冒号的“中文 / English:”标题（`QT()`，12 号）；分区内子电路用洋红粗体小标题（如 RESET、BOOT）。不再给每个模块画闭合红框，分区线即模块边界。
- **电源与地**：一律用标准电源/地符号直接挂在引脚或节点上（`PWR()`/`GND()`）；去耦电容可画成“电源符号—电容—地符号”的独立竖直支路并在下方注明“靠近 U3”。
- **连线**：模块内部用正交导线（`W()`，不显示网络名），T 形分支落在导线端点；跨模块、芯片多引脚用短线 + 网络名（`NL()`，标签位于线上方、靠外端）。芯片引脚标签按引脚等距成列，空脚打蓝色 ×（`NC()`）。
- **器件属性**：两脚器件属性文字统一放置——竖放在右侧（位号在上、数值在下），左侧拥挤时用 `side='L'`；横放在上下。
- **说明文字**：每个分区底部 3~4 行 7 号灰色说明，写额定值、默认状态、待调试项和“为什么这样接”，不写成实测结论。
- **首页**：版本记录表（版本 / 日期 / 修改摘要）、页面目录、功能介绍、系统框图（红色功率路径、蓝色控制路径、带箭头），框图避开标题栏保留区。
- **验收**：每页导出 PNG（`getPngFile(name, {width: 3000})` 看细节），检查文字压线、标签重叠、符号压标题；再跑网表比对与原理图 DRC。

## 首页总览与页面说明

- 在原理图最前面设置设计总览，优先独立为首页，按顺序展示版本信息、功能介绍、页面目录与介绍、系统功能框图。简单工程可以放在首张电路页顶部，但应保留足够阅读空间，不能挤占电路或右下角保留区。
- **版本信息**：顶部写明中性设计名称、当前版本、日期和设计阶段；版本记录表至少包含版本、日期及修改摘要，真实记录变更，不虚构审核、测试或完成状态。
- **功能介绍**：用简短文字列出用途、供电条件、主要输入输出、控制方式及关键额定参数，明确已实现的设计内容与待确认事项，避免把设计目标写成实测结果。
- **页面目录与介绍**：逐页列出真实页码、页名、模块和本页作用，例如“电源与主控：输入保护、稳压、主控最小系统”；增删或重排页面后同步更新目录及跨页引用。
- **系统功能框图**：用非电气矩形、连接线及箭头表示实际系统结构，标注电源流、信号方向、接口名称和关键电压。区分功率路径与控制路径，例如“5V 输入 → 保护 → MOS → 负载”和“3.3V → 主控 → MOS 驱动”，不能暗示负载电流经过主控稳压器。框图属于说明图，不创建真实电气网络，也不能替代电路原理图。
- **各页页头**：每张电路图页最上方留出统一说明带，显示版本、页名、本页功能摘要及必要的跨页关联；页头、模块标题和图纸标题栏信息保持一致。
- 默认使用 A4，根据总览内容安排单独首页或增加图页；标题、表格、框图与电路模块都避开水印和标题栏。导出后检查目录、框图可读性、箭头方向以及页码一致性。

## 器件朝向、连线与视觉规范

以下为参考原理图中电源、接口、按键及音频等页面提炼的通用排版方法，结合本流程的红框分区使用。

- **先决定朝向，再走线**：输入侧朝来向，输出侧朝去向。串联电阻、电感、保险丝沿主通路水平放置；上拉电阻朝上接电源，下拉电阻、去耦电容及保护支路通常竖直朝下接地。不为迁就默认符号方向而增加大段绕线。
- **以引脚功能为准**：对连接器、MOS、二极管、LED 及集成电路可局部旋转或镜像，使主通路更直接；每次变换后读取并核对真实引脚号、名称和坐标，确认源漏、极性及输入输出没有接反，不能仅凭符号外观推测。
- **电源模块**：输入电源在左，输入电容作为对地竖直支路，稳压器在中，输出电容和输出电源在右；反馈与使能就近形成易读支路。并联电容的上下节点分别对齐，电源在上、地在下。
- **接口与总线**：接口符号与串联阻容按信号去向排列；多根相关信号平行、等间距，串联电阻对齐成列，上拉电阻放上方，ESD 保护和对地电容放下方。必要时采用标签避免长距离交叉，但不隐藏模块内部主要电路。
- **按键与控制**：输入节点、上拉、滤波、保护和按键的关系在局部直接画出；按键按下接地、有效电平及启动配置一目了然。
- **正交与节点**：导线优先水平或垂直，减少折返、交叉和大回环；分支优先 T 形并核对连接点，避免四向交叉造成歧义。导线不穿过器件本体、无关引脚、位号或参数文字；不同网络的交叉不得产生意外连接。
- **电源和地符号**：公共电源及地优先使用方向一致的标准电气标识，减少到处出现的短线文字；区分电气网络标识与普通说明文字，不用普通文字冒充连接。
- **文字层级与对齐**：模块标题、关键说明、位号、数值及封装信息有明确层级；同类器件和信号按行列对齐，文字保持水平可读，旋转器件后复核属性文字位置，必要时单独移动文字。
- **适度留白**：模块内部形成紧凑、完整的局部电路，模块之间留足空白，不把器件均匀撒满方框。说明放在对应电路附近的空白处，避免与节点和参数混排。
- **参考范围**：提炼排版方法，不机械复制参考图的器件参数、页尺寸、配色或电气方案；默认 A4、红色模块框及右下角保留区规则继续适用。多页按功能命名，需要时添加真实页码的跨页指引，不使用未经核对的页码。

## 修改与验收

- 页面右下角的默认水印、标识及标题栏为保留区。先按当前模板的实际边界预留空白及适当间距，器件、连线、网络标签、模块框和说明文字均不得覆盖；不要用固定坐标假定不同图纸模板的保留区相同。空间不足时移动模块、增加图页或调整图纸，导出预览再次检查是否遮挡。
- 默认增量修改已有工程，先保存备份，再局部调整；移动已接线器件时同步处理连线和标签，不能遗留旧位置的悬空短线。保留不受影响模块、位号及图元，不为排版调整整体删除重画。仅右下角水印遮挡时，移动被遮挡模块及对应边框即可；只有确需整体重构时才说明理由并保留原版。
- 元器件符号、引脚、位号、型号、标签及连线均应位于模块框内部并与红框保持可见间距；靠框过近时优先调整局部器件位置或框大小，不让框线穿过符号或文字。
- 新增器件后重新计算受影响模块面积和页面边界，不把新增器件挤在框外。
- 核对全部元器件均有模块归属，无遗漏、重复或框外散件。
- 核对实际页面可容纳全部模块、文字和标题栏，页面内不存在符号、位号或标签互相遮挡。
- 核对每个模块有红色边界或明确红色分隔线以及可读标题，缩放到整页时能识别功能结构，局部查看时能读清型号和网络名。
- 导出预览检查页面裁切、文字大小、红框颜色及连线可读性；同时重新核对网表与电气连接，视觉整理不能代替电气检查。
